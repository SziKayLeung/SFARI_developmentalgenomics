# Transcriptome sequencing of human brain across development
This directory is a repository of scripts pertaining to whole cDNA transcriptome profiling and targeted sequencing of the human cortex dissected from 47 donors (21 male and 26 
female, 26 prenatal and 21 postnatal) aged 6 weeks post-conception (WPC) to 83 years. 

For more details, please refer to the paper:   
[An atlas of expressed transcripts in the 
prenatal and postnatal human cortex]([https://www.biorxiv.org/content/10.1101/2023.09.20.558220v1](https://www.biorxiv.org/content/10.1101/2024.05.24.595768v1)) by R.A.Bamford, 
SK.Leung, K.Chundru,..,J.Mill.
